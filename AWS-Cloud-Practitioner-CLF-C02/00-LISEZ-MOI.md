# Préparation AWS Certified Cloud Practitioner (CLF-C02)

## ⭐ Fichiers à utiliser pour s'entraîner (interactifs, à ouvrir dans un navigateur)

Dans ces fichiers, **la réponse est masquée** : il faut d'abord choisir une option (ou écrire sa réponse pour
les questions ouvertes), puis cliquer sur **« Valider et voir la réponse »**. Les bonnes réponses s'affichent en vert,
les erreurs en rouge, et un score est calculé en direct.

| Fichier | Contenu |
|---|---|
| `02-Questions-Reponses-interactif.html` | 182 questions par domaine + 7 scénarios, avec score |
| `03-Examen-blanc-interactif.html` | Examen blanc de 65 questions avec **chrono de 90 min** ; le corrigé complet se débloque une fois les 65 questions validées |
| `05-Cas-pratiques-visuels.html` | 17 cas pratiques avec schémas d'architecture ; la question type et le piège à éviter s'affichent après votre réponse |
| `06-50-questions-pieges-interactif.html` | **50 questions pièges** sur les confusions les plus fréquentes, avec explication du piège pour chacune |
| `AWS-CLF-C02-Preparation-complete.html` | Tout réuni (cours + questions + examen blanc + fiche mémo) |

Le bouton **« ↺ Recommencer »** efface vos réponses pour refaire une série.

## Ordre conseillé
1. Lire **01** (guide de cours)
2. Étudier les schémas de **05** pour visualiser comment les services s'assemblent
3. S'entraîner avec **02** (questions par domaine)
4. Faire les **50 questions pièges (06)** pour repérer vos confusions
5. Passer **03** en conditions réelles (chrono lancé)
6. Revoir ses erreurs, puis relire **04** la veille de l'examen

> Note : AWS fait évoluer ses services régulièrement (renommages, services retirés). Vérifiez le guide officiel
> de l'examen CLF-C02 sur aws.amazon.com/certification pour la liste à jour des services couverts.
