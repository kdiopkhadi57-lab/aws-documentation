50 questions pièges CLF-C02 — celles qui font échouer le plus de candidats

Version interactive recommandée : 06-50-questions-pieges-interactif.html (réponses masquées jusqu'à votre validation). Ces questions ciblent les confusions les plus fréquentes : services qui se ressemblent, responsabilité partagée, options d'achat, plans de support, classes de stockage. Lisez chaque mot de la question : le piège est souvent dans un détail.

1. Une entreprise veut bloquer les tentatives d'injection SQL ciblant son Application Load Balancer. Quel service utiliser ?

Choisissez une réponse

✅ Réponse : D — WAF filtre la couche 7 (SQLi, XSS). Piège : Shield protège contre le DDoS, pas contre l'injection SQL.

2. Quel est l'objectif PRINCIPAL d'un déploiement Amazon RDS Multi-AZ ?

Choisissez une réponse

✅ Réponse : A — Multi-AZ = disponibilité. Piège : le standby ne sert pas les lectures ; pour la performance, ce sont les Read Replicas.

3. Qui est responsable de l'application des correctifs du système d'exploitation invité d'une instance Amazon EC2 ?

Choisissez une réponse

✅ Réponse : B — Sur EC2 (IaaS), l'OS invité est géré par le client. AWS s'occupe de l'hyperviseur et du matériel.

4. Quel est le plan de support AWS le MOINS cher offrant un accès 24h/24 et 7j/7 aux ingénieurs support par téléphone ?

Choisissez une réponse

✅ Réponse : C — Business est le premier plan avec téléphone 24/7. Piège : Developer = e-mail, heures ouvrables seulement.

5. Une base Amazon RDS est surchargée par des requêtes de lecture issues de rapports. Quelle solution améliore les performances ?

Choisissez une réponse

✅ Réponse : C — Les Read Replicas déchargent les lectures. Piège classique : Multi-AZ ne change rien aux performances de lecture.

6. Une instance EC2 a été compromise et mine des cryptomonnaies en communiquant avec des serveurs malveillants. Quel service détecte ce comportement ?

Choisissez une réponse

✅ Réponse : B — GuardDuty détecte une activité malveillante en cours (logs VPC Flow, DNS, CloudTrail).

7. Une équipe veut identifier automatiquement les logiciels non patchés présentant des vulnérabilités connues (CVE) sur ses instances EC2. Quel service ?

Choisissez une réponse

✅ Réponse : A — Inspector recherche les vulnérabilités logicielles. Piège : GuardDuty détecte des menaces, pas des CVE.

8. Une entreprise utilise EC2, AWS Fargate et AWS Lambda. Elle veut une remise en échange d'un engagement d'usage, tout en gardant la flexibilité de changer de famille d'instance et de Région. Quelle option ?

Choisissez une réponse

✅ Réponse : D — Seul le Compute Savings Plan couvre EC2, Fargate et Lambda, toutes familles et Régions.

9. Quelle affirmation sur les Security Groups est correcte ?

Choisissez une réponse

✅ Réponse : B — Security Group : avec état, Allow uniquement, niveau instance. Les autres propositions décrivent une NACL.

10. Quels services utilisent les Edge Locations AWS ? (Choisissez-en deux.)

Choisissez 2 réponses

✅ Réponse : A, C — CloudFront (cache) et Route 53 (DNS) s'appuient sur les Edge Locations, tout comme Shield et WAF.

11. Pour AWS Lambda, laquelle de ces tâches N'EST PAS de la responsabilité du client ?

Choisissez une réponse

✅ Réponse : C — Lambda est serverless : AWS gère l'OS et le runtime. Le client garde code, permissions et données.

12. Quel outil génère la liste de tous les utilisateurs IAM d'un compte avec l'état de leurs mots de passe, clés d'accès et MFA ?

Choisissez une réponse

✅ Réponse : A — Credential Report = niveau compte, tous les utilisateurs. Piège : Access Advisor montre les services utilisés par une identité.

13. Qui décide de la Région AWS dans laquelle les données d'un client sont stockées ?

Choisissez une réponse

✅ Réponse : B — Le client choisit la Région ; AWS ne déplace pas les données sans action du client.

14. Quel est le plan de support le MOINS cher donnant accès à l'ensemble des contrôles AWS Trusted Advisor ?

Choisissez une réponse

✅ Réponse : C — Tous les contrôles Trusted Advisor dès le plan Business. Basic et Developer n'ont que les contrôles de base.

15. Un responsable financier veut recevoir un e-mail dès que les dépenses PRÉVUES du mois dépassent 5 000 $. Quel service ?

Choisissez une réponse

✅ Réponse : B — Budgets envoie des alertes sur les coûts réels ou prévus. Piège : Cost Explorer analyse mais n'alerte pas.

16. Une entreprise n'a encore rien déployé sur AWS et veut estimer le coût mensuel de son architecture cible. Quel outil ?

Choisissez une réponse

✅ Réponse : A — Rien n'est encore déployé : seul le Pricing Calculator permet d'estimer. Cost Explorer s'appuie sur des dépenses existantes.

17. Laquelle de ces tâches ne peut être effectuée QUE par l'utilisateur root ?

Choisissez une réponse

✅ Réponse : B — Fermer le compte est réservé au root, comme modifier les paramètres du compte ou restaurer des permissions IAM.

18. Lequel de ces transferts de données est GRATUIT ?

Choisissez une réponse

✅ Réponse : D — Le trafic entrant est gratuit. Sortie vers Internet, inter-Régions et inter-AZ sont facturés.

19. Un site ajoute automatiquement des serveurs pendant les pics et les supprime quand le trafic baisse. Quel concept cela illustre-t-il ?

Choisissez une réponse

✅ Réponse : C — Élasticité = ajuster automatiquement à la hausse ET à la baisse. Piège : la scalabilité seule n'implique pas la réduction.

20. Un logiciel est licencié par socket physique et l'entreprise veut réutiliser ses licences existantes. Quelle option EC2 ?

Choisissez une réponse

✅ Réponse : B — Les Dedicated Hosts donnent la visibilité sur les sockets et cœurs physiques (BYOL). Les instances dédiées ne le permettent pas.

21. Selon le modèle de responsabilité partagée, qui configure les politiques de bucket Amazon S3 ?

Choisissez une réponse

✅ Réponse : A — Configurer les accès aux données (politiques de bucket, ACL, Block Public Access) est toujours la responsabilité du client.

22. Combien de zones de disponibilité une Région AWS comprend-elle au MINIMUM ?

Choisissez une réponse

✅ Réponse : C — Minimum 3 AZ par Région (certaines en ont plus).

23. Une application doit stocker des clés d'API tierces et en effectuer la rotation automatique. Quel service ?

Choisissez une réponse

✅ Réponse : B — Secrets Manager = rotation automatique. Piège : Parameter Store stocke mais ne fait pas de rotation native ; KMS gère des clés de chiffrement.

24. Un auditeur demande le rapport SOC 2 d'AWS. Où le client peut-il le télécharger ?

Choisissez une réponse

✅ Réponse : D — Artifact fournit les rapports de conformité d'AWS. Piège : Audit Manager prépare VOS audits.

25. Un bucket S3 a été supprimé. Quel service indique quel utilisateur a effectué la suppression ?

Choisissez une réponse

✅ Réponse : A — CloudTrail enregistre qui a fait quel appel d'API. Piège : Config montre l'état de la ressource, pas l'auteur.

26. Une entreprise veut savoir quand une ressource devient non conforme à ses règles internes (ex. volume EBS non chiffré) et conserver l'historique de sa configuration. Quel service ?

Choisissez une réponse

✅ Réponse : D — Config évalue la conformité et garde l'historique de configuration.

27. Quel service répartit le trafic entrant entre plusieurs instances EC2 situées dans plusieurs zones de disponibilité ?

Choisissez une réponse

✅ Réponse : B — ELB répartit le trafic entre instances et AZ. Piège : Route 53 fait du routage DNS, pas de l'équilibrage de charge au niveau des instances.

28. Un même message doit être envoyé simultanément à plusieurs abonnés (e-mail, SMS et une fonction Lambda). Quel service ?

Choisissez une réponse

✅ Réponse : B — SNS = publication/abonnement (fan-out). SQS = file d'attente consommée par un traitement. SES = e-mails uniquement.

29. Quelle est la solution la plus simple et la moins chère pour héberger un site web composé uniquement de HTML, CSS et images ?

Choisissez une réponse

✅ Réponse : A — Site statique = hébergement de site web S3 (souvent avec CloudFront). Pas de serveur à gérer.

30. Des données sont rarement consultées mais doivent être disponibles en quelques millisecondes et résister à la perte d'une AZ. Quelle classe S3 ?

Choisissez une réponse

✅ Réponse : C — Standard-IA : accès rare, millisecondes, multi-AZ. Piège : One Zone-IA ne résiste pas à la perte d'une AZ.

31. Des copies de fichiers pouvant être facilement recréées sont rarement consultées. Quelle classe S3 est la MOINS chère tout en offrant un accès en millisecondes ?

Choisissez une réponse

✅ Réponse : A — Données recréables + accès rare = One Zone-IA, environ 20 % moins cher que Standard-IA.

32. Une entreprise doit conserver des archives 10 ans au coût le plus bas possible ; un délai de récupération de 48 heures est acceptable. Quelle classe ?

Choisissez une réponse

✅ Réponse : D — Deep Archive est la classe la moins chère ; récupération en 12 à 48 h.

33. Quelle est la portée d'un volume Amazon EBS ?

Choisissez une réponse

✅ Réponse : B — Un volume EBS est lié à une AZ. Pour le déplacer : snapshot puis restauration dans une autre AZ.

34. Des centaines d'instances EC2 Linux réparties sur plusieurs AZ doivent lire et écrire dans le même système de fichiers. Quel service ?

Choisissez une réponse

✅ Réponse : D — EFS = NFS partagé, multi-AZ, pour Linux. Piège : FSx for Windows est pour SMB/Windows ; EBS est attaché à une instance.

35. Pour quelle charge de travail les instances Spot sont-elles le mieux adaptées ?

Choisissez une réponse

✅ Réponse : B — Spot convient aux tâches tolérantes aux interruptions. Jamais pour une base de production ou un service critique.

36. Quelle est la durée maximale d'exécution d'une fonction AWS Lambda ?

Choisissez une réponse

✅ Réponse : B — 15 minutes maximum. Au-delà : EC2, ECS/Fargate ou AWS Batch.

37. Une banque exige un module matériel de sécurité dédié à un seul client, dont elle contrôle entièrement les clés. Quel service ?

Choisissez une réponse

✅ Réponse : C — CloudHSM = HSM matériel dédié (single-tenant). KMS est un service managé partagé.

38. Quels avantages AWS Shield Advanced apporte-t-il par rapport à Shield Standard ? (Choisissez-en deux.)

Choisissez 2 réponses

✅ Réponse : A, C — Shield Advanced : protection des coûts DDoS + SRT 24/7 + WAF inclus. Il est payant ; Shield Standard est gratuit.

39. Quel est l'effet d'une Service Control Policy (SCP) dans AWS Organizations ?

Choisissez une réponse

✅ Réponse : B — Une SCP fixe un plafond ; elle n'accorde rien et ne s'applique pas au compte de gestion.

40. Quel pilier du Well-Architected Framework porte sur la capacité d'une charge de travail à se rétablir après une panne ?

Choisissez une réponse

✅ Réponse : C — Fiabilité = se rétablir des pannes, scaler horizontalement, tester la reprise.

41. Quelle perspective du AWS Cloud Adoption Framework couvre la formation des équipes, la culture et la gestion du changement ?

Choisissez une réponse

✅ Réponse : D — La perspective People couvre culture, formation, structure et changement.

42. Une entreprise migre sa base MySQL auto-gérée vers Amazon RDS for MySQL sans modifier le code de l'application. Quelle stratégie ?

Choisissez une réponse

✅ Réponse : A — Replatform = optimisation sans changer l'architecture. Rehost serait une base MySQL installée telle quelle sur EC2.

43. Lequel de ces services est un service GLOBAL (non rattaché à une Région) ?

Choisissez une réponse

✅ Réponse : C — IAM est global. EC2, RDS sont régionaux ; EBS est lié à une AZ.

44. Une entreprise veut exécuter des services AWS dans son propre data center avec les mêmes API qu'AWS. Quel service ?

Choisissez une réponse

✅ Réponse : A — Outposts installe l'infrastructure AWS chez le client. Local Zones restent chez AWS, près d'une ville.

45. Une entreprise veut réduire la latence pour des utilisateurs du monde entier en mettant en cache les vidéos et les images près d'eux. Quel service ?

Choisissez une réponse

✅ Réponse : D — CloudFront met en cache le contenu dans les Edge Locations. Piège : Global Accelerator ne met rien en cache.

46. Quel plan de support inclut un Technical Account Manager (TAM) DÉSIGNÉ ?

Choisissez une réponse

✅ Réponse : D — TAM désigné = Enterprise. Enterprise On-Ramp donne accès à un pool de TAM.

47. Quels sont les avantages de la facturation consolidée d'AWS Organizations ? (Choisissez-en deux.)

Choisissez 2 réponses

✅ Réponse : A, B — Facture unique + remises sur volume cumulées (et partage des RI/Savings Plans). La facturation consolidée est gratuite.

48. Un analyste veut exécuter des requêtes SQL directement sur des fichiers stockés dans Amazon S3, sans gérer de serveur. Quel service ?

Choisissez une réponse

✅ Réponse : B — Athena = SQL serverless sur S3. Redshift est un entrepôt de données à alimenter.

49. Une équipe atteint la limite du nombre d'instances EC2 autorisées dans une Région. Quel service permet de demander une augmentation ?

Choisissez une réponse

✅ Réponse : C — Service Quotas permet de consulter et demander l'augmentation des limites. Trusted Advisor ne fait que signaler les limites proches.

50. Quel service informe un client qu'une maintenance planifiée par AWS va affecter l'une de SES instances EC2 ?

Choisissez une réponse

✅ Réponse : A — AWS Health Dashboard montre les événements qui affectent VOS ressources. CloudWatch surveille les métriques.
